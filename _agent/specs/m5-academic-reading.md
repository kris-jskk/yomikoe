## 2. Document profile (phase 2; ING-11, D40)

### 2a. Module

`api/hearnarro/ingestion/profile.py` (new):

```python
ProfileClass = Literal["prose", "mixed", "math"]
CitationStyle = Literal["numeric", "author_year", "none"]

@dataclass(frozen=True)
class DocumentProfile:
    math_share: float        # (equation block chars + inline maths span chars) / all read chars
    display_per_page: float  # display equation blocks / pages with a text layer
    code_share: float        # code block chars / all read chars (ING-10)
    citation_style: CitationStyle
    scanned_share: float     # pages with has_text_layer False / pages (ING-2)
    cls: ProfileClass        # computed class
    override: ProfileClass | None = None   # user's class (LIB-1 badge); wins when set
    author_year_citations: Literal["read", "skip"] = "read"   # TERM-3 toggle

    @property
    def effective(self) -> ProfileClass: ...   # override or cls
    def to_json(self) -> str: ...
    @classmethod
    def from_json(cls, s: str | None) -> "DocumentProfile": ...   # None -> PROSE_DEFAULT

PROSE_DEFAULT: DocumentProfile   # what a document ingested before M5 behaves as (today's rules)

def compute_profile(pages: list[Page], blocks: list[LogicalBlock]) -> DocumentProfile: ...
```

Thresholds (D40, proposed and tunable on the fixtures, constants at the top of the module):
`MATH_SHARE_MATH = 0.15`, `DISPLAY_PER_PAGE_MATH = 1.0` → `math`; `MATH_SHARE_PROSE = 0.02` and zero
display equations → `prose`; else `mixed`. Citation style: count of numeric bracket clusters
(the `citation` group of `_PATTERN` in `normalize.py`) versus author–year parentheticals
(`\((?:[A-Z][\w'’-]+(?: et al\.)?(?:,| and| &)?\s?)+,? \d{4}[a-z]?\)`) over body block text; the larger
count wins when ≥ 3, else `none`. Inline maths mass uses `LogicalBlock.math_spans` (§3a); until phase 3
lands it, inline mass is 0 and the class rests on display equations (the worker says so in the report).

### 2b. Where it hooks (settles the ordering question)

The profile pass runs **before** mathspeak, in `ingest()` (`api/hearnarro/ingestion/pipeline.py`):

```
pages = classify_pages(pages)
blocks = merge_blocks(order_document(pages))
profile = compute_profile(pages, blocks)                 # NEW, phase 2 (ING-11)
for block in blocks:
    segments.extend(split_sentences(block, ..., profile=profile))   # stage 5 normalize gets it
apply_mathspeak(segments, blocks, pages, profile)        # NEW, phase 3 (MATH-1..4), after stage 5
return IngestResult(..., profile=profile)
```

So "stage 6" in D40 is the pass over the finished (merged) blocks, placed after `merge_blocks` and
before the `split_sentences` loop, because stage 5's normalizer already needs the class for the
bracket rule; mathspeak is the step after the `split_sentences` loop. Q4 in §7 asks the docs sync to
reword D40's "stage-6" accordingly. `IngestResult` gains `profile: DocumentProfile = PROSE_DEFAULT`.

Normalizer signature (phase 2 adds the parameter, default keeps today's behaviour, so every existing
caller and test is unchanged):

```python
def normalize(text: str, *, heading: bool = False,
              profile: DocumentProfile = PROSE_DEFAULT,
              math_spans: Sequence[tuple[int, int]] = ()) -> tuple[str, list[int]]: ...
```

Bracket rule by `profile.effective` (ING-11): `prose`: today's citation drop. `math`: a bracket group

## 3. Mathspeak and code listings (phase 3; MATH-1..4, D36, D37, ING-10)

### 3a. Data carried from stage 1 to the reader

There is no glyph class: the finest geometry stage 1 keeps is `Span` (`text, bbox, font, size, bold,
italic, superscript`) inside `Line` inside `Block` (`models.py`). D37's "glyph geometry" therefore means
span geometry: a span is a run of one font, size and superscript flag, so a script, a limit, a
numerator and a denominator are separate spans or lines with their own bboxes. If a structure needs a
finer unit (a fraction rule with no text, per-glyph baselines inside one span), the worker reports it
and stops for a decision; widening stage 1 changes `extract.py` and the goldens (Q5).

Additions to `api/hearnarro/ingestion/models.py`:

```python
@dataclass
class MathSpan:
    start: int                 # offsets into LogicalBlock.text
    end: int
    display: bool              # True for a whole equation block, False for an inline span
    runs: list[Span]           # the stage 1 spans, in reading order, geometry kept
    label: str | None = None   # "3" from a trailing "(3)" (MATH-4)

LogicalBlock.math_spans: list[MathSpan] = field(default_factory=list)   # set by merge_blocks
BlockType gains "code"                                                    # ING-10
```

`merge_blocks` (`merge.py`) sets `math_spans`: the equation branch keeps the raw merged text as
`LogicalBlock.text` (it is what the reader shows) and records one display `MathSpan` over it (today
the branch puts `equation_cue(lines)` in `text` and the raw text in `raw_text`; `raw_text` stays for
the D14 excluded-mass guard); an inline block appended through the `block.inline` branch records an
inline `MathSpan` over the characters it added; a math-font run inside a body line (`_is_math_font` in
`classify.py`) records an inline `MathSpan` too. Invariant, tested: `block.text[s.start:s.end]` equals
the joined text of `s.runs` up to the whitespace merge_lines changes.

### 3c. Reading convention (fixed so spoken.txt writers and the reader agree)

ClearSpeak-style plain English, lower case, one wording per symbol. The machine-readable copy of this
table is `api/scripts/math_convention.json`; the phase-3 mathspeak symbol table loads that file, and
`api/scripts/check_math_convention.py` checks both expected-text sources (`formula_*.spoken.txt`,
`math_speech.jsonl`) against its banned wordings, raw-symbol leaks and lower case. Punctuation is
prosody only (EVAL-10 strips it before scoring): a comma closes a group before a power or ends an
argument list, and a comma is never spoken as "comma". Numbers stay digits (the backend's `num2words`
shim speaks them), including chemical counts and equation numbers; a number written as a word in the
source prose stays a word.

**General rules**

| Rule | Wording |
| --- | --- |
| Variables | read as letters, lower case: `E` "e", `D_{KL}` "d sub k l", `mc²` "m c squared" |
| Juxtaposition | silent (`2ab` "2 a b"); "times" for `×`, and between or before parenthesized factors that are not function arguments (`2(k−1)` "2 times k minus 1") |
| Grouping `( )` | silent; a comma closes a group before a power (`E[X]²` "e of x, squared") |
| Relations | carry "is" in running maths (`k ≥ 1` "k is greater than or equal to 1", also inside prose: "for every t is greater than or equal to 1"); drop "is" inside a subscript condition of a large operator or an indexed family (`∑_{i>r}` "the sum over i greater than r of", `(X_t)_{t≥0}` "x sub t for t greater than or equal to 0") |
| Unary minus | "minus" (`−x` "minus x"), never "negative" |
| Display-line prefix (MATH-4) | a numbered display equation starts "equation N: " (`(3)` at the right margin, "equation 3: y equals a x plus b"); unnumbered displays have no prefix |
| MATH-1 fallback | "equation N" (or "equation") then the symbols left to right by the names in this table |

**Operators and relations (MATH-3)**

| Symbol | Wording | Symbol | Wording |
| --- | --- | --- | --- |
| `+` | plus | `=` | equals |
| `−` `-` | minus | `≠` | is not equal to |
| `±` | plus or minus | `<` / `>` | is less than / is greater than |
| `∓` | minus or plus | `≤` / `≥` | is less than or equal to / is greater than or equal to |
| `×` | times | `≪` / `≫` | is much less than / is much greater than |
| `÷` | divided by | `≈` `≃` | is approximately equal to |
| `·` `⋅` | dot (product and placeholder argument: `p(·)` "p of dot") | `≡` | is equivalent to |
| `∂` | partial (`∂f/∂x` "partial f over partial x") | `∝` | is proportional to |
| `∇` | del | `:=` `≔` `≜` | is defined as |
| `∞` | infinity | `∼` `~` | distributed as (no "is": it qualifies a noun phrase, `x ∼ N(0,1)` "x distributed as n of 0, 1") |
| `!` | factorial | `⊥` | is perpendicular to |
| `⊗n` power | to the tensor power n | `∥` (single, inside an argument list) | parallel (`D_KL(p ∥ q)` "d sub k l of p parallel q") |
| `∘` | composed with | `→` | "approaches" in limits and "tends to" (`n → ∞` "n approaches infinity"); "to" between sets after a colon (`f : X → Y` "f from x to y") |
| `↦` | maps to | `⇒` `⟹` | implies |
| | | `⇔` `⟺` | if and only if |

**Logic and sets**

| Symbol | Wording | Symbol | Wording |
| --- | --- | --- | --- |
| `∀` | for all | `∈` | in (ClearSpeak SetMemberSymbol "in"; also as the main relation: `a ∈ A` "a in a") |
| `∃` / `∄` | there exists / there does not exist | `∉` | not in |
| `¬` | not | `∋` | contains |
| `∧` / `∨` | and / or | `⊂` / `⊆` | is a subset of / is a subset of or equal to |
| `∴` | therefore | `⊃` / `⊇` | is a superset of / is a superset of or equal to |
| `∪` / `∩` | union / intersection | `∖` | minus |
| `∅` | the empty set | `{a, b}` | the set a, b |
| `{x : P}`, `{x \| P}` | the set of x such that p | `{x_i}_{i=1}^n` | the set of x sub i for i equals 1 to n |

The bar `|` has three readings, chosen by its role: "given" in a conditional probability or
expectation (`p(y | x)` "p of y given x", `E[D_t | F_{t−1}]` "e of d sub t given f sub t minus 1");
"such that" in set-builder notation; "the absolute value of" when paired around an expression
(`|x − y|`). A paired `‖·‖` is "the norm of"; a single `∥` is "parallel".

**Greek letters**: by name, lower case: alpha, beta, gamma, delta, epsilon (also `ϵ`), zeta, eta,
theta (also `ϑ`), iota, kappa, lambda, mu, nu, xi, omicron, pi, rho, sigma (also `ς`), tau, upsilon,
phi (also `ϕ`), chi, psi, omega. Capitals that differ from Latin letters take "capital": capital gamma,
capital delta, capital theta, capital lambda, capital xi, capital pi, capital sigma, capital upsilon,
capital phi, capital psi, capital omega. Capitals that look Latin (`Α`, `Β`, ...) are read as the Latin
letter.
